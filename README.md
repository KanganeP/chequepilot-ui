# ChequeFlow UI

A modern React-based frontend application for Cheque Processing and Analytics. The application provides an intuitive dashboard for cheque management, OCR result visualization, status tracking, and reporting.

## 🚀 Features

* Modern React 18 application
* Material UI (MUI) components
* Responsive user interface
* Interactive charts using Recharts
* React Router for navigation
* Smooth page transitions
* Tailwind CSS support
* Dashboard and analytics views
* Cheque processing workflow visualization

## 📋 Prerequisites

Before running this project, ensure you have:

* Node.js (v18 or later recommended)
* npm (v9 or later)

Verify installation:

```bash
node -v
npm -v
```

---

## 📦 Installation

Clone the repository:

```bash
git clone <repository-url>
cd chequeflow-ui
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Running the Application

Start the development server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

---

## 🏗️ Build for Production

Create an optimized production build:

```bash
npm run build
```

Build files will be generated in the `build/` directory.

---

## 🧪 Running Tests

Execute unit tests:

```bash
npm test
```
